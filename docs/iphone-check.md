# 実機で確かめること

## 1. 採用箱（duo-box へ分離、0.30.0）

- [ ] 今の DuoRemote に上書きで入り、ホーム画面の名前が DuoBox になっている
- [ ] 接続先とトークンが引き継がれていて、リモートがそのままつながる
- [ ] アプリを開くとホーム（採用箱）が出て、「リモート」と「キーボード」のタイルが並んでいる
- [ ] 「リモート」を押すと、いつもの接続の画面になる。右下の家アイコンでホームへ戻れる
- [ ] 接続中は、右上の「…」メニューの先頭に「ホームへ戻る」があり、押すと接続したままホームへ戻れる（もう一度「リモート」を開くと、つながったままの画面に戻る）
- [ ] 接続中は「ホーム」ボタンが出ない（操作の邪魔をしない）
- [ ] 「キーボード」を押すと、追加の手順の案内が出る
- [ ] 設定アプリ → 一般 → キーボード → キーボード → 新しいキーボードを追加 に DuoFlick が出て、追加できる
- [ ] 追加した DuoFlick で「フルアクセスを許可」をオンにできる
- [ ] メモ帳などで DuoFlick キーボードに切り替えて、日本語入力と変換ができる
- [ ] キーボード内の設定画面が開けて、設定の変更が残る

## 2. サンドボックス版（DuoBox Sandbox、0.30.0 ビルド74）

- [ ] DuoBox と並べて入れられる（別アプリとして増える）
- [ ] 名前が DuoBox Sandbox で、アイコンが赤い箱になっている
- [ ] 開くと赤系の箱だけが出て、「まだ何も入っていません」と表示される（中身は入れていない）

## 3. ホログラム（DuoBox Sandbox）

### ビルド85（手順1：生値表示＋壁の奥行き初期値＋作り直しの歯止め）
- [ ] 起動直後の部屋で、壁が折り目より奥に下がって見える（wallRecess 初期値 40mm）
- [ ] 計測パネル③の wallRecess スライダーが 0〜100mm まで動かせる
- [ ] 計測パネル⑥に「真の生値 rel(m)」と「変換後 head(m)」の2行が出る
- [ ] 顔を左右に動かすと rel の x の符号がどう変わるか（右へ動いて増えるか減るか）
- [ ] 顔を近づける・遠ざけると rel の z がどう変わるか（符号と増減）
- [ ] 折り目位置が微振動しても画面が作り直しで固まらない（0.2mm 未満の変化は無視される）

### ビルド86（手順2：位置合わせマーカー）
- [ ] 計測パネル⑦のトグルを入れると、画面の角と折り目に印が出る（上パネルの角＝水色、折り目＝黄色、下パネルの角＝マゼンタ）
- [ ] 頭を左右・上下に動かしても、角の印が画面の角に張り付いたままか（泳ぐ場合はその量と向き）
- [ ] 印の動きが頭の動きより大きいか小さいか（寸法・カメラ位置のずれの目安）
- [ ] 印が頭と逆向きに動く場面があるか（軸対応が逆の目安）
- [ ] 折り目の黄色い印（特に中央）が、折り目で上下に段差なくつながって見えるか

### ビルド87（手順3：格子）
- [ ] 床と壁に格子（20mm間隔）が出ている
- [ ] 折り目のところで、床の格子と壁の格子がつながって見える（段差や間隔のずれがないか）
- [ ] 頭を動かしたとき、格子が床と壁に張り付いて見えるか（浮いて泳がないか）
- [ ] 計測パネル③のトグルで格子を消せる・戻せる

### ビルド88（手順4：絶対位置のみ・ホーム／ゲイン廃止）
- [ ] 顔トラッキングで視点が動く（従来どおり追従するか）
- [ ] パネル⑥に「軸対応後(m)」の行が出ている／ホーム記録ボタンと視差ゲインのスライダが無くなっている
- [ ] マーカー（⑦）を出して頭を左右・上下に動かし、印が頭と同じ向きに動くか（逆なら⑥の軸対応を直す）
- [ ] 以前ホームを記録していた場合でも、視点の基準が変にずれていないか

### ビルド89（追加1：身長の自動決定）
- [ ] キャラの頭が上パネルの上端で見切れていない（頭を前後・上下に動かしても）
- [ ] パネル③に「身長（自動の上限）」が出ていて、折り角や壁の下げ量を変えると値が変わる
- [ ] 身長が小さくなりすぎていないか（机に置いた通常の姿勢で）

### ビルド90（追加A：前後位置 p・台座の割合・wallRecess 30mm）
- [ ] wallRecess の初期値が 30mm になっている
- [ ] パネル③の「前後位置 p」スライダーでキャラが前後に動く（0＝手前の端、0.5＝中央、1＝折り目）
- [ ] p を 1 より大きくすると折り目より奥（床の角の方向）へ下がる／角より先には行かない
- [ ] パネル③に「前後位置 p（実際）」と「台座が下画面に乗る割合」が出る（手前へ動かすと割合が増え、奥へ下げると減る）
- [ ] 台座が床の面から浮いていない・沈んでいない

### ビルド91（追加B：向き w・身長 0.6 倍＋余裕 8mm で自動縮小）
- [ ] 角度を変えるとキャラの向きが変わる（110°以下では床に垂直、170°近くでは真上に近づく）
- [ ] 台座は床に張り付いたままで、キャラだけが傾く（足が台座の中心からずれない）
- [ ] パネル③に「向き w（実際）」が出る／「向き w は角度で自動」のトグルを切ると手動スライダーで変えられる
- [ ] 身長が 0.6×パネル高くらいになっている（パネル③「身長（自動）」）
- [ ] 頭を大きく動かしても頭が見切れない（余裕が足りない分は身長が自動で小さくなる）

### ビルド92（追加C：見切れ余裕の表示）
- [ ] パネル⑧「見切れ余裕」が出る（頭・足・台座の縁・体の左右・高さ 1/4・1/2・3/4）
- [ ] 頭を動かすと数値が変わる／キャラが端に寄ると、その点の余裕が小さくなる
- [ ] 見切れる位置まで寄せると、その行が赤くなる
- [ ] 「—」になる窓がある（その窓では数えられない点）

### ビルド93（追加D：角度ごとの p・w 記録）
- [ ] パネル⑨「角度ごとの p・w 記録」が出る（いまの角度・p・w が表示される）
- [ ] 「この角度の p と w を記録」を押すと、一覧に角度・p・w が追加される
- [ ] 2つの角度で記録すると、その間の角度では p と w が補間されて効く（p・w とも自動のとき）
- [ ] 記録の範囲の外の角度では既定に戻る（p=0.5、w は角度の smoothstep）
- [ ] 一覧の「削除」でその行が消える
- [ ] アプリを再起動しても記録が残っている
- [ ] パネル③の「前後位置 p は角度で自動」を切ると、手動スライダーが効く

### ビルド94（追加E：顔ロスト保持・開かないと動かない）
- [ ] 顔を見失っても視点がすぐには戻らず、1〜2秒はその場に留まる
- [ ] 見失ったままにすると、数秒かけてゆっくり基準の位置へ戻る
- [ ] 画面を60°未満に閉じると「画面を開いてください」が出て、ホログラムが止まる
- [ ] 開き直すとホログラムが再開する

### ビルド95（手順5：1€フィルタ＋先読み）
- [ ] 頭を止めているとき、視点がふらつかない（前の指数平滑より安定する）
- [ ] 頭を速く動かすと、視点が遅れずについてくる
- [ ] パネル⑥の「最小カットオフ」「速度係数 β」「先読み」スライダーで効きが変わる
- [ ] 先読みを最大（50ms）まで上げると行き過ぎて見える／0に戻すと収まる

### ビルド96（手順6：両画面で同じフレーム状態を共有）
- [ ] 顔を動かしても、折り目の継ぎ目で上下の絵に段差が出ない
- [ ] 下画面だけ遅れて見える感じがない

### ビルド97（修正A〜F）
- [ ] A：パネル③の p・w スライダー（自動を切った状態）とパネル⑥の 1€ スライダーが効く
- [ ] B：パネル②に 1pt あたり 0.166mm、折り目の位置、カメラ位置（pt と mm、上端・折り目からの距離）が出る
- [ ] B：カメラが取れないときは「カメラ位置：既定値」と出る／カメラが下側になる向きでは「カメラが下側：向きを変えてください」と出る
- [ ] B：全開（180°）で、折り目の上下で絵に段差やズレが出ていないか（下パネルを軸から 4mm 離した影響の確認）
- [ ] C：パネル⑧の余裕が行ごとに1つの値で出て、負のときだけ赤くなる
- [ ] E：記録が1件だけでも全角度でその p・w が効く
- [ ] E：記録の範囲の外では端の記録の値を保つ（既定値に飛ばない）／角度を変えても身長や p・w が急に跳ねない
- [ ] F：パネル⑥に rel.z（符号つき）と距離のクランプ前／後が出る
- [ ] F：パネル③の p スライダーの右端で、キャラが床の角まで届く

### ビルド98（F2：全開付近で部屋の角を畳む）
- [ ] 145° で、部屋の角が折り目へ近づき、壁と床が滑らかにつながって見える（パネル③の「実効（mm）」は wallRecess 30mm のとき約 23.5）
- [ ] 全開（180°）で、角が折り目に畳まれ、壁が画面と同じ面の背景になる（「実効（mm）」が 0.0）
- [ ] 130° 以下では「実効（mm）」が wallRecess と同じ値になる
- [ ] ゆっくり開閉しても、途中で角・壁・床・格子・キャラの絵が跳ばない

### ビルド99（再レビュー 2-1〜2-4）
- [ ] 全開（180°）で、格子と床の線が折り目でつながって見える（パネル③の「折り目の離れ（mm）」が 0.00）
- [ ] 折ると「折り目の離れ（mm）」が増え、135° で約 1.93、90° 以下で 3.85 になる。折っている途中も格子が折り目で不自然にずれない
- [ ] 60° 付近で開閉しても表示がちらつかない（60° 未満で「画面を開いてください」が出て、70° 以上で消える）
- [ ] 開き直したとき、作り直しの止まり感がなくすぐ絵が出る
- [ ] 顔を外して戻したときに、視点が行き過ぎない

### ビルド100（設定のテキストコピー）
- [ ] 計測パネルの末尾に「⑩ 設定のコピー」が出て、「設定をテキストでコピー」を押すと「コピーしました」と出る
- [ ] メモ帳などに貼り付けると、基本・カメラ・調整値・1€ フィルタ・定数・角度ごとの p・w 記録・現在の状態の7つの見出しが全部入っている
- [ ] 貼り付けたテキストの調整値（壁の下げ量、p、w、身長の倍率、格子とマーカー、1€ の3つ）が、パネルで合わせた値と一致する
- [ ] p・w の記録が全件入っている（記録が無いときは「記録なし」）
- [ ] パネル内のテキストが約0.5秒ごとに最新になり、長押しの選択でもコピーできる
